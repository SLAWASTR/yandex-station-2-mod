# 🚀 Яндекс Станция 2 — Ultimate Mod & Guide

> **Полный комплекс модификации Яндекс Станции 2 (YNDX-00051 / Станция 2 / Миди на Amlogic AXG):**  
> Получение вечного Root без разборки, блокировка автообновлений, постоянный Dropbear SSH, Apple AirPlay, нативный Spotify Connect с PlayPlay DRM, аппаратные сенсорные кнопки и двусторонняя синхронизация громкости с Алисой.

## ✨ Возможности модификации

- 🔓 **Root без вскрытия корпуса**:
  - Активация инженерного режима через локальный DNS-спуфинг сервера Яндекса.
  - Постоянный ADB root (`uid=0`) на порту `5555`, сохраняющийся после перезагрузок.
- 🛡️ **Блокировка автообновлений (Anti-OTA)**:
  - Нейтрализация фонового демона `updatesd`, заглушка `applier`, фиктивный ключ `ota.key`.
  - Защита от ночных сбросов и окирпичивания root-доступа.
- 💻 **Полноценный Dropbear SSH (порт 2222)**:
  - Легковесный SSH-сервер с современным `ed25519` ключом хоста для удобного управления через терминал с ПК или смартфона.
- 🍏 **Apple AirPlay (Shairport Sync 4.3 + tinysvcmdns)**:
  - Беспроводная трансляция с iPhone, iPad, Mac без задержек и без разрывов.
  - Мгновенное обнаружение в меню AirPlay под именем **`Yandex Station 2`**.
  - Автоматическое освобождение аудиовыхода при переключении между AirPlay и Spotify.
- 🎵 **Spotify Connect (Spotiya + PlayPlay DRM Decoder)**:
  - Нативный 32-битный аудиовыход в ALSA без конфликтов разделяемой памяти (IPC `dmix`).
  - Встроенный аппаратный эмулятор DRM **PlayPlay** (решает проблему с отказом серверов Spotify выдавать стандартные ключи).
  - Максимальный битрейт до 320 kbps (Extreme Quality).
- 🎛️ **Аппаратные сенсорные кнопки и умный мост громкости**:
  - Сенсорные кнопки **`+`** и **`−`** на корпусе меняют громкость Spotify.
  - Одиночный короткий тап по центру — **Play / Pause**.
  - Двусторонняя синхронизация: громкость, выставленная голосом (*«Алиса, тише»* / *«громкость 4»*) или в приложении «Дом с Алисой», мгновенно меняет громкость трека в Spotify и двигает ползунок на телефоне.
  - Плавное приглушение музыки (*Ducking*) на время диалога с Алисой.
- 🗣️ **Голосовой поиск и быстрые команды**:
  - *«Алиса, включи [песню / альбом / исполнителя]»* — поиск и воспроизведение в Spotify.
  - Быстрые команды без слова «Алиса»: *«стоп»*, *«пауза»*, *«дальше»*, *«назад»*, *«тише»*, *«громче»*.

## ⚡ Быстрая установка «всё в одном»

Если колонка уже подключена к компьютеру по ADB:

```bash
# 1. Склонируйте репозиторий на компьютер
git clone https://github.com/SLAWASTR/yandex-station-2-mod.git
cd yandex-station-2-mod

# 2. Скопируйте установочные скрипты на колонку
adb -s <IP_КОЛОНКИ>:5555 push scripts /tmp/station2_scripts

# 3. Запустите автоматическую установку
adb -s <IP_КОЛОНКИ>:5555 shell "sh /tmp/station2_scripts/install-all.sh"

# 4. Удалите временные файлы
adb -s <IP_КОЛОНКИ>:5555 shell "rm -rf /tmp/station2_scripts"
```

Скрипт автоматически проверит архитектуру, смонтирует файловую систему, пропишет автозапуск всех служб, скачает и скомпилирует недостающие зависимости, после чего перезапустит плеер.

## 🗣️ Шпаргалка по управлению

### Голосовые команды (через Алису):
- *«Алиса, включи [название трека / группы / альбома]»* — поиск и воспроизведение в Spotify
- *«Алиса, дальше»* / *«следующий трек»* — переход к следующему треку
- *«Алиса, назад»* / *«предыдущий трек»* — переход к предыдущему треку
- *«Алиса, пауза»* / *«стоп»* — пауза
- *«Алиса, играй»* / *«продолжи музыку»* — возобновление
- *«Алиса, громче»* / *«тише»* — изменение громкости на 10%
- *«Алиса, громкость на 4»* / *«громкость семь»* — точная установка уровня (0–100%)

### Короткие команды без слова «Алиса»:
- *«Стоп»* / *«Пауза»*
- *«Дальше»* / *«Следующий»*
- *«Назад»*
- *«Тише»* / *«Громче»*
*(Для работы убедитесь, что в приложении «Дом с Алисой» в настройках Станции включены «Быстрые команды»).*

### Сенсорная панель на колонке:
- **Одиночный тап по центру:** Play / Pause
- **Кнопка `+`:** Увеличить громкость на 5%
- **Кнопка `−`:** Уменьшить громкость на 5%
- **Удержание центральной кнопки (> 0.6 сек):** Вызов Алисы (погода, умный дом и т. д.)

## 🎛️ Управление службами в консоли (SSH / ADB)

```bash
# Статус Spotify и текущий трек
spotiya status

# Интерактивный псевдографический интерфейс (TUI) с поиском и управлением
spotiya tui

# Управление воспроизведением из консоли
spotiya play "Queen"
spotiya pause
spotiya resume
spotiya next
spotiya volume 60

# Перезапуск служб
/etc/init.d/S99spotify-connect restart
/etc/init.d/S99zentware restart

# Просмотр логов в реальном времени
tail -f /tmp/spotify-connect.log       # лог плеера Spotify
tail -f /tmp/spotiya-midi-bridge.log   # лог сенсорных кнопок и громкости
```
